## Criterios de no cierre

- No aprobar por inferencia a partir de una fecha corregida, de un artículo de prensa, de un test verde ni por el solo hecho de tener referencias bibliográficas.
- Si un campo SQL requiere cambios adicionales, tramitarlo como nuevo expediente de metadatos, **no** como efecto lateral de E-5.
- Las cinco sinopsis heredadas de SQL tienen revisión jurídica y de sustitución independiente de la revisión E-5 de su versión actual.
- El derecho a publicar fotografías y los derechos comerciales sobre terceros no se desprenden de esta matriz.
- El sitio estático protegido puede continuar accesible; activar anuncios o API no forma parte de este expediente.

**Control de conteo:** 18 altas (expediente previo) + 18 medias + 22 bajas = 58 piezas identificadas sin aprobación automática.
